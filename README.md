# 蜡笔小新棋盘 H5

运行时使用原棋盘美术、FGUI切图与布局、小新Spine动画；40格顺序、位置和模型取自原项目，机会卡、倍率、首图建筑成本和扭蛋奖励由原配表导出。

目前是浏览器本地存档版。投骰、走格、九类格子、机会卡、监狱、护盾/租金、破坏、12格盲盒、建造换图、扭蛋和存钱罐累计领取可运行。好友对手在本地模拟，未连接原账号服及社交服务。

范围：已按原表导入前三图：春日部(base1)、野原家(base41)、幼稚园(base2)；首图建筑成本使用原表，超出已导入数值的地图采用本地计算。存钱罐目前只做累计领取，未移植完整好友基金玩法；画册仅记录扭蛋所得贴纸数量。其他限时活动、机会卡触发的独立挑战、线上匹配和付费系统未接入。FGUI旧占位引用未作为真实插图使用：机会卡插图读取原ChanceIcon的_01资源；UI使用默认原版分支，不混用assets_CN。FGUI仍由H5适配器呈现，未完整移植全部转场和粒子特效。

## 运行

需要HTTP服务打开，不能双击file://入口（浏览器模块与资源请求需要HTTP）。本机预览可在此目录执行Python http.server，或使用常见静态网站服务。

## 文件

- src/engine.mjs：本地棋盘状态与结算。
- src/fgui.mjs：原FGUI布局读取与控件绑定。
- src/scene.mjs：原网格、UV和地图的绘制。
- scripts/export_config.py：只读导出原配置及中文文案。
- tools/export_assets.py、tools/export_fidelity_ui.py、tools/inspect_board_scene.py、tools/inspect_grid_shader.py、tools/export_fund_prop.py、tools/export_dice_prop.py：原资源导出。
- assets-source.json、fidelity-assets-source.json、assets/scene/original-scene-evidence.json：素材来源。
- tests/engine.test.mjs、scripts/browser-check.mjs：规则与浏览器操作检查。

## 构建

用Node执行 scripts/build.mjs，产物在dist。发布复用.openai/hosting.json中的同一网站身份。
本次画面校正：使用原35°相机、0.9棋盘比例、格子各自材质与顶点色；按原矩阵绘制前后景和格面文字，小新按0.01×0.24比例及原Center朝向显示；存钱罐和普通骰子使用原3D模型，普通投骰重放原横向动画及6×6落点修正。建造图读取map_base坐标与原贴图大小。

动态还原：普通经过/落地重放原 ani_gezi_jingguo、ani_gezi_stop（1.5倍速），连带父节点变形和原加色叠层。普通移动使用walk，捣蛋末三格使用原jump01/02/03，移动时长按原速度/距离计算，动画画框覆盖原跳跃全部边界；相机按原Cinemachine的1秒误差衰减到1%的阻尼逐帧跟随XY，并保留0.5秒启用过渡。数据在assets/scene/board-motion.json、board-overlays.json、piece-motion.json。

棋盘模型现在共用三维深度缓冲，倾斜和联动时按几何遮挡。格面数字恢复原RectTransform锚定偏移，参与深度遮挡并限定在所属格子的可见顶面；落地烟尘和扫光粒子未移植。

事件UI校正：机会卡、护盾、租金、监狱、捣蛋和盲盒使用原FGUI控件和动态皮肤；补齐原位图数字、中文艺术字、初始隐藏节点及24帧制转场。监狱保留成功/失败页和专用投骰按钮；捣蛋与盲盒使用原领奖页。数字字体之外的减号使用文本补字。飞入奖励为H5简化表现，原粒子、Spine事件演出与监狱笼子尚未完整移植。资源由tools/export_event_ui.py增量导出，来源见assets-event-ui-source.json。

落格金币：复用原Cylinder002网格、tex_jinbi贴图、金属材质及两种金币粒子参数，重放重力/限速/大小/旋转/淡出曲线；保留原CommonFlyText转场与MoneyDud/LoseMoney音效。同点骰子、经过起点、落格正负金额分别按原位置和时机展示，租金保持专属提示。粒子使用H5采样与步进，随机序列和限速积分尚未与Unity逐帧对齐。

活动：新增截图中的鼓图标里程碑和橙子排行入口，复用原FGUI弹窗、图标与CN活动配置。停留指定格子、拜访和猜取收藏按原积分及倍率推进，跨档奖励自动发放并保存在本机。倒计时读取原定日期，结束后不重置。当前H5为本机演示，暂开放原第3/6地图活动入口；排行榜仅展示本机实际成绩，不接在线比赛。卡包和限时道具奖励写入本机库存，完整开包及增益系统未移植。

棋盘显示修复：第11格按完整路径载入自己的图集，缺图会报错，不再误用普通格图集。数字保留原锚定高度、字距与自动缩放，避免越过格面。租金好友使用原FriendHeadIcon圆柱、材质参数、20°/秒旋转及经过加速曲线、站位和阴影，保留现有本地角色头像；接入原头像升起曲线，棋子推挤和整排收租格动画尚未完整移植。默认环境反射采用中性值，未加载原运行时环境立方体贴图。

活动界面校正：锁定和入榜页均使用原小新橙汁海报，锁定页保留锁头；恢复原规则卡片61%填充、榜行选页与控件组位移，避免榜单遮住倒计时；关闭按钮使用截图对应的trunk金圆红叉原图。保留实际积分，区分未入榜和已入榜状态。

格上建筑补齐：恢复第1、21、31格原默认启用的建筑子模型及GridBuildShadow投影，使用完整原子树矩阵并随格子原动画变形。40格的235个渲染节点已单独导出核对；第11格活动金币保留在conditionalProps，不作为常驻建筑绘制。数据由tools/export_grid_props.py只读导出，原底座与挂点不变。
